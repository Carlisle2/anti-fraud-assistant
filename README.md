# LLM Anti-Fraud Assistant (AI 智能反诈助手)

> **信息技术应用与社会服务（劳动教育）课程项目**
> 一个基于大语言模型（LLM）与 Streamlit 构建的助老反诈网页原型，旨在帮助长辈快速识别可疑短信、聊天记录和电话话术中的诈骗风险。

## 项目背景与痛点
随着网络通信的普及，长辈在日常中常收到伪装成“快递异常”、“账户安全”、“借款额度调整”等具有迷惑性的信息。通过调研发现，长辈的核心痛点在于：
1. **难判断**：面对制造紧迫感的文案，难以快速识别诈骗特征。
2. **不会核实**：意识到可能有问题，但不知道下一步该怎么做。

本项目并非简单“教长辈用 AI”，而是将大模型的调用过程封装起来，降低使用门槛。用户只需“输入信息 -> 查看结果”，即可获得结构化的风险分析报告。

## 核心功能与特色
- **结构化风险分析**：通过精心设计的 Prompt Engineering，强制大模型按「能不能相信 -> 风险等级 -> 为什么有风险 -> 现在应该怎么办」四段式输出，极大降低长辈的阅读门槛。
- **动态语义理解**：告别死板的“关键词匹配”，接入**阿里云百炼 (qwen-plus) API**，依靠大模型对诈骗话术进行动态语义分析。
- **降低使用门槛**：基于 Python + Streamlit 搭建 Web 界面，用户只需粘贴文本、点击按钮即可获取分析。
- **隐私保护设计**：界面显著位置提示“请勿输入身份证号、银行卡密码等敏感信息”，并在 Prompt 中设定了安全边界。

## 技术栈
- **开发语言**：Python
- **Web 框架**：Streamlit
- **大模型接口**：阿里云百炼 API (`qwen-plus`) 
- **SDK**：OpenAI Python SDK (兼容模式)
- **环境管理**：python-dotenv

## 快速开始 (本地运行)
如果你想在本地运行此项目，请按照以下步骤操作：

### 1. 克隆仓库
```bash
git clone https://github.com/你的用户名/llm-anti-fraud-assistant.git
cd llm-anti-fraud-assistant
```

### 2. 安装依赖
```bash
pip install streamlit openai python-dotenv
```

### 3. 配置环境变量
在根目录创建 `.env` 文件，填入你的阿里云百炼 API Key：
```env
DASHSCOPE_API_KEY=your_api_key_here
```

### 4. 运行应用
```bash
streamlit run app.py
```

## 提示词设计 (Prompt Engineering) 亮点
本项目的核心在于对模型输出的控制。系统内部通过 `SYSTEM_PROMPT` 严格约束了模型的角色、分析维度（陌生链接、转账要求、索要验证码、身份冒充、制造紧迫感）及输出格式，并设置了 `temperature=0.1` 来降低生成内容的随机性，确保相似输入下的回答稳定可靠。

## 实践成效与反馈
- **真实测试**：协助长辈实际分析了 3 条真实的可疑短信（涉及逾期协商、额度调整等），系统均准确识别出风险并给出了“停止操作、通过官方渠道核实”的建议。
- **用户反馈**：长辈反馈“识别还是挺准确的”。同时提出了极具价值的改进建议：希望能与手机短信系统结合，实现自动识别，减少“复制-粘贴”的操作成本。
